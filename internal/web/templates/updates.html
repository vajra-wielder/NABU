Get & update Wikipedia

Wikimedia publishes a fresh snapshot of Wikipedia regularly. The Kiwix project turns each one into a single .zim file with every page, picture and link included. NABU checks the Kiwix catalogue each time it starts and offers newer editions here.

{{.Download.File}}

You can keep reading while this runs. If the connection drops or you close NABU, the download continues from the same point next time.
