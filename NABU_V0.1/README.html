# Offline Wikipedia App

This app provides an offline version of Wikipedia with a custom GUI. It uses the Wikipedia dump files stored in the `data/` directory.

## Features
- **Search Articles**: Search for articles by title or content.
- **Hyperlinks**: Navigate between articles using clickable hyperlinks.
- **Glossary Support**: View definitions for glossary terms within articles.
- **Geographical Data**: Display articles with geographical coordinates on a map.
- **Tables**: Render tables from articles in a user-friendly format.
- **Images and Media**: Display images and media files within articles.
- **Infoboxes**: Show structured data from infoboxes.
- **Article Metadata**: Display categories and templates associated with articles.

## Setup
1. Place the Wikipedia dump files (`enwiki-latest-pages-articles-multistream.xml.bz2` and `enwiki-latest-pages-articles-multistream-index.xml.bz2`) in the `data/` directory.
